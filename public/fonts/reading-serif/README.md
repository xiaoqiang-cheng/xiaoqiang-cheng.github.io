# Reading font

Derived from Adobe Source Han Serif SC Regular (思源宋体), distributed under SIL OFL 1.1; see LICENSE.txt.

Source: https://github.com/adobe-fonts/source-han-serif/tree/release/OTF/SimplifiedChinese

Converted to WOFF2 and split into 512-codepoint Unicode ranges for common characters and a shared range for rare characters with fontTools. All characters in the original font remain available; browsers load only the ranges needed by a page. Subset font family renamed to Qzone Reading Serif to respect the reserved font name. The CSS is in src/styles/reading-font.css.
